## SysLens 0.2.0

**Новое**

- Сводка читается проще: «AMD Ryzen 5 5600X · 6C/12T · 3.7 ГГц», «16 ГБ · DDR4»,
  «CT500P3SSD8 · 465.8 ГБ · NVMe», «свободно 14.8 ГБ из 150.3 ГБ».
- Linux: сведения из `/proc`, `/sys`, `df`, `ip` и `lspci` (сборка из исходников).
- Кнопки «Обновить», «Копировать» и «Сохранить отчёт» — рядом с поиском;
  в узком окне остаются значки.

**Исправлено**

- 🔒 теперь скрывает и зарегистрированного пользователя (часто это e-mail),
  домен и имя учётной записи в путях.
- В отчёте длинные названия больше не сливаются со значением.
- Повторное нажатие F5 не запускает второй сбор сведений.
- Если система не отвечает, программа сообщает об этом и предлагает повторить.
- Названия программ с иероглифами показываются правильно.
- Пропали пустые строки вроде « бит» и « Гц».

**Как запустить:** скачайте `syslens.exe` ниже и запустите — установка не нужна.
Windows 10/11, 64-bit.

**How to run:** download `syslens.exe` below and run it — no installation needed.
