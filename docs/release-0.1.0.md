## SysLens 0.1.0

Первая версия / First release / Перша версія.

- Процессор, системная плата, память, SPD, BIOS, ОС, видеокарта, монитор,
  звук, диски, разделы, сеть и установленные программы.
- Русский, English, українська — кнопка 🌐.
- Тёмная и светлая тема, поиск по странице, скрытие личных данных 🔒,
  копирование страницы и сохранение отчёта.

**Как запустить:** скачайте `syslens.exe` ниже и запустите — установка не нужна.
Windows 10/11, 64-bit.

**How to run:** download `syslens.exe` below and run it — no installation needed.
