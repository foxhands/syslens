## SysLens 0.4.0

**Новые страницы**

- **Оценки и подсказки** — простыми словами: что тормозит компьютер («память
  занята на 90 %», «диск почти полон», «один модуль памяти вместо двух»), что
  можно улучшить (свободные слоты памяти, сколько памяти поддерживает плата),
  что давно не обновлялось (BIOS, драйверы, программы, Windows) и готов ли
  компьютер к Windows 11.
- **Сравнение** — откройте JSON-отчёт с другого компьютера и увидите различия
  в железе и программах. Страница «Изменения» со снимками убрана: её заменяет
  сравнение.

**Новое**

- **Избранное** — правая кнопка по значению закрепляет строку на сводной странице.
- **Короткая сводка одной строкой** («процессор / видеокарта / память / диск»)
  — в меню «Копировать», чтобы вставить в чат.
- **Печать и сохранение в PDF** — кнопка с принтером.
- **Страница картинкой** — кнопка с фотоаппаратом; личные данные на картинке скрыты.
- **Значок возле часов** с нагрузкой процессора и памяти (Windows).
- **Ещё три языка**: Deutsch, Español, Polski.
- **Выбор единиц**: размеры дисков как в Windows или как на коробке.
- **Проверка обновлений** с кнопкой «Скачать новую версию» — только по нажатию.
- У окна появился значок. В «О программе» — автор (Foxhand) и версия.

**Сборки**

- Windows на ARM: `syslens-windows-arm64.exe`.
- Linux: `SysLens-x86_64.AppImage` и сборка для ARM64.
- macOS (Intel и Apple Silicon): `SysLens-macos.zip` — пробная, заполняются
  основные страницы; программа не подписана (открывать через правую кнопку →
  «Открыть»).
- Scoop: `scoop install https://github.com/foxhands/syslens/releases/latest/download/syslens.json`
- Готовый манифест для winget: `winget-manifest.zip`.

**Важно**

- JSON-отчёты прежних версий для сравнения не подходят: сохраните отчёт заново.

**Как запустить:** скачайте файл для своей системы ниже и запустите — установка не нужна.

**How to run:** download the file for your system below and run it — no installation needed.
Windows: `syslens.exe`. Linux: `SysLens-x86_64.AppImage` or the `.tar.gz`. macOS: `SysLens-macos.zip`.
