## SysLens 0.3.0

**Новые страницы**

- **Нагрузка сейчас** — процессор (с графиком за минуту и по ядрам), память,
  скорость сети и место на дисках, обновляется каждую секунду.
- **Изменения** — запомните состояние компьютера и позже увидите, что
  появилось, исчезло или обновилось: программы, драйверы, устройства.
- **Батарея** — заряд, износ и число циклов (на ноутбуках).
- **Автозагрузка**, **Службы**, **Драйверы**, **Устройства USB**, **Принтеры**,
  **Обновления системы**.

**Новое**

- В списке программ теперь есть приложения из Microsoft Store; список можно
  упорядочить по имени, размеру, дате или издателю.
- Поиск ищет по всем страницам сразу.
- Щелчок по значению копирует его.
- Отчёт можно сохранить куда угодно — текстом, веб-страницей (HTML) или JSON.
- Отчёт без окна: `syslens --report отчёт.html`.
- Здоровье дисков (температура, износ, наработка) — при запуске от имени
  администратора.
- Готовая сборка для Linux: `syslens-linux-x86_64.tar.gz`.

**Исправлено**

- Длинные значения переносятся по строкам, а не уходят за край окна.
- Сведения собираются без временного файла на диске.

**Как запустить:** скачайте `syslens.exe` ниже и запустите — установка не нужна.
Windows 10/11, 64-bit.

**How to run:** download `syslens.exe` below and run it — no installation needed.
Linux: unpack `syslens-linux-x86_64.tar.gz` and run `./syslens`.
